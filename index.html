My approach in software development is:

I reject the pure use of LLMs in software development as I value creativity and craftsmanship in the "Art of Programming". With this in mind, I believe that LLM's should be specifically used for only the following conditions:

1. As a glorified reactive and interactive local search engine with my provided data and its existing parameters
2. As an error analyzer and debuggger
3. As a contextual programming tutor
4. As a cheat sheet and roadmap generator for concepts, syntax, and keywords

In no way or form should it be use to "Vibe Code" an application. It is a tool, not a replacement for humans.
